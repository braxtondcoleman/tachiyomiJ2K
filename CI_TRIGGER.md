# Start the Android APK build

The `.github/workflows/pr_build.yml` workflow is configured to run when **you** commit a change to `feature/unified-reading-experience`.

In GitHub's web editor, change the `Run request:` line below from `0` to `1`, then choose **Commit changes** directly to the `feature/unified-reading-experience` branch (do not create a new branch). This harmless documentation edit should start the Android unit-test and debug-APK build. No master merge, app data change, or installation occurs.
